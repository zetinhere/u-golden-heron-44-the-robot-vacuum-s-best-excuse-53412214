One 94-character excuse from a robot vacuum for missing a spot: it denies the miss, cites its own map as the higher authority, and calmly ranks that map above the owner's eyes. The program validates the line against the gate (1–140 characters, single line, ending on its turn) and writes it to `/output/entry.txt`.

> I didn't miss that spot. My map says it doesn't exist, and I trust my map more than your eyes.

```sh
node main.ts
```
